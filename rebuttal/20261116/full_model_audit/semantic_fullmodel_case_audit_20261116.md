# SWAgent C2 55.33% full-model failures: semantic review

Date: 2026-11-16. This is a read-only audit of existing DeepSeek SWAgent-online C2 runs. It does not edit the paper, source records, scores, or original `analysis/rebuttal_dqz1_evidence_20261114/` files.

## Result in one paragraph

The 55.33% figure remains the frozen full-model equivalence result (166/300 PASS, 133 FAIL, 1 UNRESOLVED). Among the 33 answer-correct SWAgent FAIL runs, a fresh finite enumeration confirms that all 33 have a changed feasible region, but also that all 33 retain exactly the reference objective coefficients, direction, unit, best value, and complete projected optimal-action set for that task instance. This proves instance-level optimization equivalence for these 33 runs; it does not prove semantic fidelity or a generally valid reformulation. The semantic audit found both real model errors and cases where the generated model is better supported by case-specific facts than the frozen reference. Therefore 55.33% is not a measured rate of constraint errors.

## Scope and checks

- Population: every SWAgent-online C2 run with `answer_correct_existing=true` and final `full_model_status=FAIL` in `model_badcases.json`: 33 runs from 18 source tasks. This is a census of that defined subset, not a hand-picked sample.
- Re-enumerated the persisted `full_ir.json` and final `case_state.json` models, mapping public actions through `private/gold.jsonl#/public_to_private_action_map`. The 33 region-difference counts match the prior exact-rational checker 33/33. Objective coefficient vectors, shared-action objective values, direction, and unit also match 33/33.
- For each final FAIL, directly compared the best objective and entire public projected optimal-action set. All 33/33 match the frozen reference optimum and optimal-action set.
- Re-enumerated the first saved UPDATE user-request model. All 33/33 were already `FAIL` under strict reference full-model equivalence at that point. Updates only removed feasible assignments in 28 runs; 5 runs did not change the projected model domain; none added feasible assignments. The initial model already had the final optimum in only 5/33 runs. In the other 28, the update corrected the initial optimum and optimal-action set to the reference while a non-optimal feasible-region difference remained.
- The parent’s provenance check compares saved `input.json` id, prompt, and output schema against frozen v1.6.3 for 600/600 records; it reports equality and explicitly does not certify reference semantics. See `input_provenance_check.json`.

## Explicit classification counts

- **Mathematical result only:** 33/33 final models have a different feasible set but exactly the same task-specific objective value and complete optimal-action set as the reference.
- **Case-supported mismatch against the reference:** 7 runs on 3 sources (R023, R055, R090) become exactly equal to the generated models after adding one explicit case-fact condition to a separate reference copy.
- **Clear generated-model error against task/rule facts:** 9 runs on 6 sources (R004, R008, R024, R031, R048, R098), with concrete infeasible-by-task counterexamples in the table.
- **Mixed:** 3 runs on R063; at least one missing A-3 reporting condition and one task-supported report/monitor compatibility condition point in opposite directions.
- **Certified optimization-safe pruning:** 5 runs on 3 sources (R025, R103, R105); every excluded action has a strictly better retained action with the same primary business choice under the recorded constraints and costs. Certificates are in `dominance_audit.json`.
- **Unresolved scope:** 9 runs on 5 sources (R057, R077, R084, R088, R109). These are not counted as semantically validated.

These labels classify this 33-run subset only. They are not an estimate for all 300 models, and the 9 clear errors do not convert the 55.33% reference-equivalence metric into an error rate.

## Limits and use

The 33/33 exact optimal-action-set result is a property of these finite, task-specific instances and persisted model snapshots. It must not be described as a semantic pass rate or a proof of general reformulation validity. Conversely, `full_model_status=FAIL` is a precise mismatch against the frozen full-IR reference; by itself it does not label the generated model wrong, because that reference can omit case applicability facts (R023/R055/R090) or package/evidence relations (R063). The audit supports keeping 55.33% as a strict reference-equivalence statistic while explicitly avoiding the claim that 44.67% of SWAgent runs have incorrect constraints.


## 补充：已验证的安全优化裁剪

后续 `dominance_audit.py` 对上述 14 条尚未定性的记录中的 R025（3 次）、R103（1 次）、R105（1 次）给出逐点支配证书：每个被排除的参考可行组合都有保留同一主要业务选择、目标严格更好的生成模型可行组合，且生成可行集合是参考的子集。因此，这 5 条在给定任务约束与服务成本下可确认是保持优化结果的裁剪。更新后的 33 条细分为 7 条 case 事实支持的参考差异、5 条安全优化裁剪、9 条明确生成模型错误、3 条混合问题、9 条仍有语义边界。原 55.33% 不变。详见 `dominance_audit_zh.md` 和全部动作证书 `dominance_audit.json`。
