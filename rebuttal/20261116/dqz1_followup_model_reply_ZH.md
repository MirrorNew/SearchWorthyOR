# 对 dqz1 第二项疑问的后续回复草稿

感谢您认可补充实验和分析带来的证据。我们希望进一步澄清本文的贡献定位，以及全模型等价率的具体含义。

本文的贡献首先是将题面未给出的外部规则主动发现问题明确为一个优化建模问题，并构建控制规则适用性和可见性的评测基准；在此基础上提出 SWAgent。相同骨干下的结果展示了这一问题上的进展：答案正确率和严格参考模型等价率均提高了 22.00 个百分点。

55.33% 采用的是一项严格的补充诊断：要求整个公开行动可行集合及其目标值一致，包括非最优行动。我们现已逐一审计全部 33 条“答案正确但未通过该诊断”的 SWAgent 记录。完整枚举确认，**33 条记录不仅最优值相同，连完整最优行动集合也与参考一致**。其中 28 条通过更新将初始错误的最优值及行动集合修正为正确结果，同时保留了非最优行动上的差异。

审计在其中 **12 条记录上给出了不能将严格参考不一致直接视为建模失败的具体证据**：7 条遵循了冻结参考未落实的明确题面事实，5 条具有经验证的保最优约简。这些结论都有逐例检查支持，不只是观察到最终答案相同。

例如，R090 明确说两项支持动作已从本地流程撤下，SWAgent 将其变量置零，而冻结参考仍允许将其作为独立、增加成本的动作。R055 明确说密封货物不能检查，SWAgent 排除了该任务搭配检查服务的组合。仅在参考模型的独立副本中加入这些题面条件，就能得到与生成模型完全一致的可行集合。七条记录还包括按照明确的当日处理义务解释的 R023。此外，R025、R103 和 R105 中被删除的每个行动，都有**保持同一项主要业务选择、目标严格更好**的保留行动，因此这五条记录在给定任务约束和服务成本下具有明确的安全优化裁剪证书。

我们保留原来的 55.33% 统计，将上述诊断另行报告。由此更准确的解释是：**严格参考等价检查未通过，不能统一归因于生成模型存在错误或缺失约束，也不能直接换算成外部规则纳入的失败率。** 已有轨迹还显示 156 次从初始模型不等价到最终模型完全等价的修正。这些证据支持本文在问题定义、可评测基准及规则驱动建模上的贡献，并区分了决策正确、参考一致与单项规则更新正确这三个层面。
