## 固定分析问题

1. 55.33% 是否能从原始保存模型重现；分母是 100 个 C2 源任务 × 3 次运行。
2. 未通过模型检查的记录中，分别有多少可行域差异、目标差异、单位／方向差异、缺少终态交付。
3. 答案正确但检查失败的记录，是否存在已证明正确的等价改写、只保最优的约简、原始模型错误或参考答案问题。
4. 差异是在初始建模中已经存在，还是在后续更新中引入。时间位置本身不等于因果归属。
5. 提供的 ORLM 样例能否在不泄漏答案、不删改业务条件的前提下由当前运行接口完成。

## 表述口径

全文模型一致性是相对冻结参考的诊断指标，不能直接换算成外部规则获取或更新错误率。对有效变换的解释必须给出本批实例证据；同一最优答案不能自动证明全部业务约束正确。

作者说明本批数据来自杉数的 ORLM 训练案例。现有来源材料能支持“额外收集的 ORLM 训练案例”；是否为独立真实部署案例、如何抽样、是否经过合成或改写，需要来源记录支持。信息完整的 C3 类补充任务用于测试规则已给定时的建模能力，不能单独证明 C2 的主动遗漏规则发现。
