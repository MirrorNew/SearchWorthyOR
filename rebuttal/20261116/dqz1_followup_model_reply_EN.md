# Follow-up on full-model equivalence — draft for Reviewer dqz1

Thank you for recognizing the additional evidence. We would like to clarify the scope of our contributions and what the full-model statistic establishes.

Our contributions start with formulating proactive discovery of unstated external rules as an optimization-modeling problem and constructing a benchmark that controls rule applicability and visibility. SWAgent provides an approach to this problem. The same-backbone results demonstrate progress on the resulting challenge: both answer accuracy and strict reference-model equivalence improve by 22.00 percentage points.

The 55.33% figure uses a deliberately strict diagnostic: equality of the entire projected feasible-action set and its objective values, including non-optimal actions. We have now audited all 33 SWAgent runs that returned correct answers but failed this diagnostic. Exhaustive enumeration confirms that **all 33 preserve both the optimal value and the complete optimal-action set**, not just one returned numerical answer. In 28 of these runs, updates corrected the initially incorrect optimum while a difference on non-optimal actions remained.

The audit identifies **12 runs with concrete evidence that a strict reference mismatch should not be read as a modeling failure**: seven follow explicit case facts not enforced by the frozen reference, and five admit verified optimality-preserving reductions. These are distinct from simply observing the same final answer.

For example, R090 states that two support actions have been removed from the local workflow. SWAgent fixes their variables to zero; the frozen reference still permits them as costly independent actions. R055 explicitly makes inspection impossible for the sealed cargo, and SWAgent excludes those inspection combinations. Adding these stated conditions to separate copies of the references yields exact agreement with the generated models. The seven runs also include R023 under its explicit same-day processing requirement. Separately, in R025, R103, and R105, every removed action has a strictly better retained alternative with the **same primary business choice**; these five runs admit an explicit optimality-preserving reduction certificate under the recorded task constraints and service costs.

We retain the original 55.33% statistic and report these diagnostics separately. The audit supports a more precise interpretation: **failure of strict reference equivalence cannot uniformly be attributed to incorrect or missing constraints, or interpreted directly as a failure rate for incorporating external rules.** The existing trajectories also show 156 revisions from non-equivalent initial models to fully equivalent final models. Together, these results support the value of making the problem measurable and improving rule-informed modeling, while distinguishing decision correctness, reference consistency, and the correctness of individual rule updates.
